  <h2>📘 Internship Overview</h2>
  <p>This 4-week internship focuses on developing practical data science skills using 
     <strong>Python, Pandas, Matplotlib, Seaborn, and Scikit-learn</strong>. 
     Interns complete any 4 out of 6 tasks, each designed to strengthen analytical, visualization, and machine learning capabilities.</p>
